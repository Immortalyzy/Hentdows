# Repository working rules

- Never read the user's existing library content during this or future work. Do
  not inspect, scan, index, query, open, copy, or render their existing books,
  images, manifests, library database, or library backups. Do not launch the app
  against the user's real profile for development or validation, since startup
  automatically scans registered library locations.
- Develop and test with synthetic fixtures in isolated temporary profiles and
  storage folders only. Source code and the checked-in Hentoid reference source
  may be read. Do not use existing user library data as test fixtures.
